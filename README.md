# 摄影返图工作台 · 1.7.15 原片返图

当前交付规则：绑定纯数字 QQ 号的任务直接闪传原片，不生成 ZIP；绑定微信号的任务打包 ZIP 后发送。QQ / 微信可混合排队，完成后保留返图留言。按绑定渠道区分，不把微信昵称当作账号。

## 启动与使用

双击 `启动摄影返图工作台.bat`。更新后先关闭旧窗口再启动。

1. 新建拍摄项目，或打开已有项目的 `project.json`。
2. 点击 **新建人物文件夹**，输入人物名称。
3. 选中左侧人物，点击 **添加文件夹** 或 **添加文件**。文件夹递归包含子目录；可多次添加，按完整路径去重。照片和视频自动生成预览，不进行人脸、服装或场景识别。
4. 双击素材预览，Ctrl / Shift 多选。需要调整时使用 **修改选中素材归属**；多人素材可以关联多个人物。
5. 切换 **发布选片相册**，发布当前人物。先本机预览，再复制公网链接或二维码发给模特。
6. 模特提交选片后生成原片发送任务。QQ 直接闪传原片，微信先打 ZIP 再发送。不经过网页选片时，可多选人物点击“发送选中人物全部素材”。任务列表 Ctrl / Shift 多选后点击“发送 / 继续选中任务”可批量启动。网页自动发送开关为“网页提交后自动返图”。

### 批量发布人物相册

在左侧用 Ctrl / Shift 选中多个人物文件夹，切换“发布选片相册”，点击“批量发布选中人物”。每个人物使用独立链接；空文件夹跳过，失败相册显示原因，其他人物继续发布。完成后弹出链接清单，显示人物名称、绑定 QQ / 微信号、链接和状态，可复制单个人物链接或导出 CSV。之后可通过“查看链接清单”再次查看。没有公网入口时生成的是本机地址，不能发给异地模特。

左侧人物列表空白处右键可新建人物文件夹；右键人物可重命名或删除。删除只移除项目中的人物归属，独属素材转为“未分配”，已经移动的原片仍保留在磁盘人物目录，历史返图包保留；删除前项目状态自动备份到 `backups`。

人物列表和素材列表均支持 Ctrl+A（也兼容 Alt+A）全选、Shift 连续选择、Ctrl 点击逐项选择/取消。人物多选时右侧展示这些人物的素材合集，可右键批量删除人物；添加或发布时需单选人物。素材全选仅作用于当前页。

右侧选中一张或多张素材后，可按住鼠标拖到左侧具体人物项，松开后将磁盘原片实际移动到该人物的“原片”目录，并替换原归属、更新项目路径。后台复制并校验文件后才移除源文件；同名文件自动另存，不覆盖。原位置的文件会消失。目标项会显示浅绿色；拖到空白、“全部素材”或“未分配”会取消。修改归属后需重新发布。

## 人物文件夹与原片

新建人物时立即在项目的 `人物/人物_稳定编号/` 下建立文件夹，里面的 `素材清单.csv` 记录人物名称与原片来源。名称可在界面修改；使用稳定编号避免改名丢失历史返图包。

导入默认引用原片，不移动文件；拖拽到人物时会实际移动原片。需要实体副本时点击 **复制原片到当前人物文件夹**，复制到该人物的 `原片` 子目录。移出项目不删除原片。新版 ZIP 位于项目的 `返图压缩包/任务编号/内容编号/` 下；名称为 `QQ号_账号_年月日_返图.zip` 或 `微信号_账号_年月日_返图.zip`，使用下划线替代 Windows 不允许的冒号。包内同名文件加序号，原片内容不变。旧版返图包保留。导入后请保持原文件位置与内容不变；源文件改变时需重新导入、发布和选片。

支持常见 JPG/PNG/WebP/BMP/TIFF、相机 RAW（NEF/ARW/CR2/CR3/DNG/RAF/ORF/RW2）和 MP4/MOV/M4V/AVI/MKV/WebM。具体视频编码与相机型号取决于解码器；HEIC 尚不支持。文件夹导入跳过符号链接与 Windows 联接点。

## 网页与公网入口

### QQ / 微信原片交付

在人物与素材页可同时为人物保存 QQ 号和微信号，并设置默认发送渠道。任务页的“发送渠道”可选择人物默认、QQ 或微信；先选任务，再切换渠道，接收账号会同步更新。缺少所选账号会提示补充，已发送、部分发送或结果待核对的任务不能切换渠道。直接返图创建任务时也使用任务页当前渠道选项。先核对原片指纹：QQ 直接闪传本批原片，微信独立打包后发送一个 ZIP。“微信压缩包辅助发送”提供人工核对后复制 ZIP、粘贴发送的备用方式。

QQ 复用已确认主面板并核对完整 QQ 号，通过“文件弹出菜单 → 闪传文件”一次发送本任务原片。微信按完整微信号搜索，核对联系人结果和聊天标题；昵称和相似账号不能替代微信号。客户端不提供 UIA 控件时使用 Windows 本地 OCR 备用路径，识别截屏随即清理。OCR 无法可靠核对账号或发送结果时暂停，不猜测目标。微信仍需实机验证；模拟测试和 OCR 测试图片不能证明真人聊天发送已验证。保持客户端登录，自动操作期间不要使用鼠标键盘或锁屏。

发送进度显示 ZIP 中的原片数量。客户端出现文件卡片后标记“已提交发送”，不等于对方下载完成。中断结果不确定时停止在“需核对”；核对后点击“核对中断文件”，决定跳过或重新发送。重启不会自动重发不确定任务，继续任务只打包未确认发送的原片。完成后尝试返图留言；留言失败不重发照片。旧版 ZIP 和选片保留为历史记录，不自动发送旧任务。

网页只用于预览、选片和提交，不提供原片或 ZIP 下载。缩略图最长边 360px WebP，放大图片最长边 1200px JPEG；同时最多加载 4 张缩略图，视频点击播放后加载预览。原片保持原始字节用于打包。

公网入口需由内网穿透服务转发至 `http://127.0.0.1:17860`，然后把 HTTP 或 HTTPS 根地址填入软件。填写网址不会自动建立隧道。分享期间保持软件运行、电脑在线且不休眠。未配置时仅本机访问。首次打开速度仍受公网线路和电脑上传带宽影响。

每个人物使用独立随机链接，服务端校验素材归属。修改素材后需重新发布；停止发布撤销旧链接。QQ / 微信自动发送以任务中的绑定账号为准；无法确认目标或发送结果时暂停。

## 旧项目升级

首次打开旧项目会在 `backups` 备份项目状态。已人工确认的归属、选片记录和返图包保留；未确认的自动分类转为“未分配”，可手动指定人物。旧相册暂停发布，整理后重新发布。界面与主程序已移除 AI 识别流程，不加载识别模型；旧模型文件不影响使用。

## 一键启动 OpenFrp

“发布选片相册”页新增“配置 OpenFrp / 一键启动 OpenFrp / 停止 OpenFrp”。

首次准备：
1. 在 OpenFrp 控制台创建隧道，目标为 `127.0.0.1:17860`。TCP 隧道可使用 `http://节点地址:远程端口`；HTTPS 需另外配置证书和入口。
2. 下载并解压 OpenFrp frpc 客户端，获取控制台提供的隧道配置文件。
3. 点击“配置 OpenFrp”，选择 frpc 的 EXE、隧道配置文件，并填写公网 HTTP 或 HTTPS 根地址。不要选择 OpenFrp 桌面启动器 EXE。
4. 保存后点击“一键启动 OpenFrp”。软件通过 `frpc --config 配置文件` 后台启动，不弹控制台；自动保存公网入口并更新相册链接。

软件只记住配置路径和公网地址（`.openfrp-settings.json`），不复制隧道配置中的密钥，不保存原始客户端日志。状态中的“隧道已建立”来自客户端日志，不代表已验证手机访问。关闭软件时结束由本软件启动的 frpc；停止 OpenFrp 不会停止其他服务商的进程。修改入口后请重新分享新域名的链接。

官方说明：https://docs.openfrp.net/use/frpc
